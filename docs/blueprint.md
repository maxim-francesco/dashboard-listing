# **App Name**: Greeting Display

## Core Features:

- Text Input: Allow the user to enter text in a text field.
- Display Greeting: Display the input 'hello world' greeting to the user on the screen.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to evoke a sense of calm and simplicity, avoiding overly vibrant or saturated colors.
- Background color: Off-white (#F5F5F5) for a clean, unobtrusive backdrop that complements the light blue.
- Accent color: Pale green (#90EE90) for interactive elements such as the input field and buttons.
- Font: 'Inter', a grotesque-style sans-serif, for a modern, neutral look suitable for both headlines and body text.
- Simple, centered layout with clear, unobstructed design to emphasize the greeting.
- A subtle fade-in animation when the greeting is displayed to add a touch of polish.
